# 常见问题

先按「现象」找，每条都给一句结论 + 怎么验证。原理部分见 [03-检测方法与判读标准.md](03-检测方法与判读标准.md)。

---

## 一、跑不起来

**双击 bat，窗口一闪就没了**
在 PowerShell 里手动跑，看完整报错：

```powershell
powershell -ExecutionPolicy Bypass -File .\netcheck.ps1 -NoBrowser
```

**提示「无法加载文件……禁止运行脚本」**
Windows 默认策略禁止跑脚本。用 `一键网络自检.bat` 启动（里面已带 `-ExecutionPolicy Bypass`），
或临时放开当前会话：`Set-ExecutionPolicy -Scope Process Bypass`。不要改全局策略。

**安卓装不上，提示「解析包错误」**
说明文件没下完（有些网盘的下载器会把 `.apk` 存成 `.apk.zip`，或下载中断）。重新下载，核对文件大小与人提供的数值一致。

**安卓提示「未知来源」**
作者用的是自签名证书，没有应用商店背书。允许当前文件管理器安装即可。

## 二、数字看不懂

**为什么「百度」也测，它跟墙没关系**
它是**对照组**。如果百度也不通，说明问题出在本地（宽带断了、DNS 挂了、路由器没连上），
与「被墙」无关——这时候看 GitHub 那一堆红是没有意义的。

**为什么有的点位显示「受限」而不是「不通」**
「受限」= TCP 连上了，但 TLS 握手被掐掉。这是最典型的干扰形态，也是「网站打不开但 ping 通」的原因。
「不通」= 连 443 都连不上。

**为什么「HTTPS 状态码 403」还判「优秀」**
评级只看连通性（TCP 建连），不看响应码。403/404 说明链路完全正常，只是那个路径不让访问。
报告里展开详情能看到具体状态码。

**为什么同一个点位两次跑，数值差很多**
正常。建连耗时会受运营商路由抖动、Wi-Fi 信号、手机省电策略影响。建议连跑三次看中位数，
而不是拿单次数字下结论。桌面端的历史 CSV 就是为这个准备的。

**平均建连延迟为什么只算成功的点位**
失败的点位没有「建连耗时」这个值。把它们算进平均会把结论拉得离谱。失败数单独在「异常目标」卡里。

## 三、和加速工具一起用

**我开着瓦特工具箱（Watt Toolkit）/ Clash，测出来反而更差**
先看报告顶部环境标签：

- 如果 IP 显示 `127.0.0.1` → 走的是**本地反代**（hosts 模式），测到的是「你到本机反代」的延迟，
  不代表到真实服务器的速度。要对比真实直连，得关掉它再跑。
- 如果显示「系统代理开启」但 IP 是真实 IP → 本工具用原生 socket，**不走系统代理**，
  所以测的仍是直连（这恰好是想要的结果：知道不加速时有多惨）。
- 安卓上开了 Clash 类 VPN → 报告会标「VPN 已启用」。VPN 在系统层接管，socket 绕不过，
  测到的就是规则处理后的结果。

**加速开着，「GitHub 主站」好了，但「GitHub Git 传输」还是红**
说明加速规则只覆盖了部分域名。Git 传输走的是 `github.com/git/...`，有些规则只放行网页路径。
展开详情看错误原因：如果是「连接被重置」，就是路径级阻断。

**hosts 里有映射，但 IP 还是真实 IP**
说明 hosts 没生效（被其他工具接管），或你用的是「系统代理模式」而不是 hosts 模式。

## 四、关于隐私与安全

**会上传我的数据吗**
不会。程序只发起连接、只读响应头。没有任何上报、统计、崩溃收集、更新检查。
报告只包含域名、IP、耗时、状态码。

**为什么忽略证书校验，安全吗**
只对「测量」有意义：目的是判断链路通不通，不是建立可信通道。程序不传输任何敏感数据，
请求就是一个 `GET`。但这也意味着**不能拿它判断「这个网站是否被中间人攻击」**——
证书有问题时报告仍然显示正常。

**安卓要存储权限吗**
不要。报告写在应用私有目录，导出走系统分享面板（你选发到哪）。没有存储权限、没有相册权限。

**卸载安卓应用后报告还在吗**
不在。报告在应用私有目录里，卸载即清空。要留档请先「导出报告」。

## 五、点位相关

**为什么没有测 xxx 域名**
因为 14 个点位是「实际最常卡住的地方」的取舍，不是全量清单。想加就按
[CONTRIBUTING](../CONTRIBUTING.md) 第三节改，两端一起改。

**能不能只测某一个域名**
当前版本不支持单点重测（界面和脚本都没做）。临时办法：把 `$Targets` / `Targets.all` 里其他行注释掉再跑。
这是一个明确的待办，不是「设计如此」。

**Docker 的两个点位都红，是不是不能用了**
不一定。`registry-1.docker.io` 是 `docker pull` 走的通道，`hub.docker.com` 是官网。
国内直连经常两个都红，配一个国内镜像加速地址就能 pull；官网红了不影响 pull。

**Hugging Face 一直超时**
国内直连 huggingface.co 经常不可用。报告里判「不通」是对的。要么开加速，要么用镜像站/离线包。

## 六、报告文件

**HTML 报告能发别人看吗**
能。是单个静态文件，CSS 内联、没有外链脚本和图片，断网也能打开。但**它含你的出口 IP 与解析结果**，
发给外人前想一下要不要紧（一般没什么，只是内网出口 IP 与 DNS 服务器地址）。

**CSV 用 Excel 打开中文乱码**
安卓端导出的 CSV 带 UTF-8 BOM，Excel 能认。Windows 端 `Export-Csv -Encoding UTF8` 在 5.1 上也带 BOM。
如果还是乱码，用「数据 → 从文本/CSV 导入」并选 UTF-8。

**报告目录越来越满**
Windows 在 `reports\`，安卓在应用私有目录，每次跑一份 HTML + 一份 CSV。可以直接删，程序不会依赖历史文件。

## 七、其它

**为什么版本号是四段（1.0.0.0）**
因为 Windows 端与安卓端共用同号，四段能细分到「只改文档」这一级。规则见 [CONTRIBUTING](../CONTRIBUTING.md) 第五节。

**能商用吗 / 能改吗**
能，Apache-2.0 允许商用、允许闭源分发。但必须保留作者署名并在程序里标注项目地址，
见 [ADDITIONAL-TERMS.md](../ADDITIONAL-TERMS.md)。

**发现它测的结果和我实际体验不符**
请带上 `reports/*.csv` 里那几行 + 你的网络环境（运营商、是否开加速器、是否 VPN）提 Issue。
同一个域名在不同网络下结论完全不同，没有这些信息无法判断。
