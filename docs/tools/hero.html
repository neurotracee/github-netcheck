ON-DEVICE·NO UPLOAD
GitHub 网络自检
14 个点位，DNS / TCP / TLS / HTTP 四段分别计时。
卡在哪一段、慢在谁身上，一次自检就说清楚。
全部在本机跑完，不上传任何数据
不打点、不埋数据、不接第三方统计
四段拆开计时，不是只给一个总耗时
解析慢、握手慢、首字节慢，指向的原因完全不同
Windows 与安卓，同一份点位表、同一套评级
两端结果可以直接对读，换设备不用换判断标准
评级按 TCP 建连延迟
≤120ms 优秀≤400ms 良好≤1000ms 一般>1000ms 较慢
