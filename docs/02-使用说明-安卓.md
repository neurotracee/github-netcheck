# 安卓端使用说明

安卓端是一个 APK，界面与桌面端报告同一套信息层级，只是把三栏压成了一栏。

## 安装

1. 到 [Releases 页面](https://github.com/neurotracee/github-netcheck/releases/latest) 下载 `NetCheck-<版本号>.apk`。
2. 点开安装。系统提示「未知来源 / 不允许安装未知应用」时，允许你正在使用的文件管理器安装即可。
3. 支持 Android 8.0（API 26）及以上；**通用包**，不含 native 库，arm64 / armeabi / x86 都能装。

> 签名是作者自签的证书，没有购买应用商店的数字签名，所以系统会提示「未知来源」。这不影响功能。

## 权限

只有两个，都只服务于测量本身：

| 权限 | 用来做什么 |
| --- | --- |
| `INTERNET` | 发起 socket 连接（14 个测试点位 + 一次 DoH 对照） |
| `ACCESS_NETWORK_STATE` | 读当前网络类型、系统代理、VPN 状态、私有 DNS、DNS 服务器 |

**没有**存储权限（报告写在应用私有目录，导出走系统分享）、没有位置、没有通讯录、没有短信、没有相机。
也没有任何统计/崩溃上报 SDK。

## 界面怎么用

打开就是首页，自上而下：

1. **标题区**：`NET CHECK · 本机自检` + 时间 + 点位数 + 用时。
2. **环境标签**：当前网络（Wi-Fi / 移动数据 / VPN）、系统代理、VPN、私有 DNS、hosts 条数、DNS 服务器、API 配额。
3. **按钮**：
   - `开始自检` —— 跑全部 14 个点位；
   - `只测 GitHub 系（更快）` —— 跑 11 个点位，跳过 Hugging Face 与 Docker。
4. **进度卡**（运行中）：`正在测试 3 / 14` + 当前点位名 + 进度条 + `停止`。
5. **汇总卡**（跑完）：可连通数、平均建连延迟、最快、异常目标数，下面一行总结文字。
6. **逐条结果**：每条左侧竖条颜色表示评级；第一行点位名 + 右侧评级标签；第二行域名；第三行解析到的 IP 与 DoH 对照；
   第四行是 DNS / TCP / TLS / HTTP 四段数值；下面是细进度条、用途说明，失败时还有一行红色错误原因。
   **点任意一条会展开细节**：评级依据、HTTP 状态码、本机解析、DoH 对照、四段耗时逐项、用途说明。再点一次收起。
7. **页脚**：测试方法、评级阈值、DoH 说明、版本号、原项目地址（点一下复制到剪贴板）。

跑完之后的按钮变成：`重新自检` / `只测 GitHub 系` / `导出报告` / `分享 CSV`。

## 设置与关于（右上角齿轮）

点标题右侧的 **⚙** 进设置面板，自上而下：

| 项 | 说明 |
| --- | --- |
| 界面语言 | 中文 / English。英文只换界面骨架的文字，报告正文与点位说明仍是中文 |
| 外观 | 跟随系统 / 浅色 / 深色，改完立即生效 |
| 报告保存位置 | 选一个文件夹（SAF 授权，只给这一个目录）。设了之后导出直接写进去，不再弹分享面板；可随时「清除」改回分享 |
| 更新检查方式 | 自动（每次启动静默查一次，没网就不响）/ 手动（只有点「检查更新」才联网） |
| 更新源 | Gitee（国内默认）/ GitHub。选中的源连不上会自动换另一个再试 |
| 版本与更新 | 显示当前版本号，右侧「检查更新」按钮会去读远端版本号并告诉你是否已是最新 |
| 关于与开源信息 | 单独一页：指导作者、开发（豆包工作任务的 Agent × DeepSeek-V4.1-Flash）、Apache-2.0、原项目地址、镜像地址、隐私说明、二次开发三条硬要求、维护节奏、Star 与赞赏说明 |

设置存在本机 SharedPreferences（`netcheck_settings`），不进任何云端、不需要账号。

## 导出报告

- **导出报告**：默认把本次 HTML 报告交给系统分享面板（发微信「文件传输助手」、发邮件、存网盘都行）；
  如果在设置里选了保存位置，就直接写进那个文件夹，并在页面顶部提示成功。
  文件在应用私有目录 `files/reports/`，文件名 `netcheck-<时间戳>.html`。
- **分享 CSV**：同上，文件是 `netcheck-<时间戳>.csv`，带 UTF-8 BOM，Excel/WPS 打开中文列名不乱码。

分享出去的报告是**单个静态 HTML**：CSS 内联、没有外链脚本和图片，断网也能打开，转发给别人不掉样式。

## 和桌面端不一样的地方（都是有原因的）

| 项 | 桌面端 | 安卓端 | 原因 |
| --- | --- | --- | --- |
| 「本机 443 端口被监听」 | 有（`Get-NetTCPConnection`） | 没有，改为显示 VPN / 私有 DNS | 安卓不允许普通应用枚举端口 |
| 「系统代理」 | 读注册表 `Internet Settings` | 读 `ConnectivityManager` 默认代理 | 安卓没有那个注册表项 |
| hosts 条数 | 读 `%WINDIR%\System32\drivers\etc\hosts` | 读 `/system/etc/hosts` | 安卓上这个文件通常为空，读到几条算几条 |
| DoH 对照 | 先解析 `dns.alidns.com` 再连 | **直连 223.5.5.5**，SNI 仍写 `dns.alidns.com` | DNS 被污染时，安卓端仍能取到对照值 |
| 走不走系统代理 | 不走（原生 socket） | 不走（原生 socket），但**VPN 在系统层接管，绕不过** | 平台机制不同，报告顶部会标「VPN 已启用」 |
| 报告打开方式 | 自动用默认浏览器打开 | 需要手动点「导出报告」 | 应用内没有内置浏览器组件，避免多一个 WebView |

## 手机上测出来的数字和电脑不一样，正常吗

正常，而且**通常应该不一样**。原因可能有三层：

1. 手机走的是移动数据或 Wi-Fi，出口 IP、路由、运营商互联质量都和电脑不同；
2. 手机上可能开着 Clash 类 VPN 工具（系统层接管，本应用的 socket 无法绕过），电脑上可能只开了系统代理（本应用绕过）——
   两者测到的根本不是同一条链路；
3. 安卓的 DNS 走系统 `netd`，可能启用了「私有 DNS（DoT）」，解析路径与 Windows 不同。

想让两端可比：**关掉两家设备上所有加速/代理/VPN，连同一个 Wi-Fi**，各跑一次，把两份 HTML 放在一起看。
